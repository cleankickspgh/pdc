# PDC Modern Website Starter

## Import into Bolt
1. Download and unzip this project.
2. In Bolt, create/import a project from the folder or upload the ZIP.
3. Run `npm install` and then `npm run dev`.

## Current scope
- Homepage design system and responsive homepage
- Header/footer
- Product and market data scaffolding
- SEO-ready Next.js App Router foundation
